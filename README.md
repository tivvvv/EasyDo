# EasyDo

EasyDo 是一个 local-first 的任务管理和日历应用. 第一阶段以 Web 端为主, 后续可演进到移动端和桌面端.

当前版本为 EasyDo 1.2.0. 应用完全在浏览器本地运行, 不需要账号或网络服务.

## 1.2 功能

- 月, 周, 日和可配置范围的日程视图, 按时间展示每天任务.
- 支持日历快速编辑, 跨天任务, 全天与定时任务转换, 拖动改期和 15 分钟时间吸附.
- 支持重叠任务分栏, 冲突与过期提示, 当前时间线, 精确拖动预览和拖动调整时长.
- 支持舒适与紧凑密度, 周末显示, 7 天, 14 天和 30 天日程范围, 以及工作时段设置.
- 月视图提供当天安排, 完成进度和本周迷你日历, 周日历提供待安排任务区.
- 新建, 编辑, 完成, 恢复, 复制, 手动排序, 批量修改和回收站管理.
- 每天, 工作日, 每周, 每月和每年重复任务, 支持间隔, 结束日期和本次, 后续或全部修改范围.
- 子任务与完成进度, 任务开始前本地通知提醒.
- 日期, 时间, 预计时长, 备注和四级优先级.
- 自定义分类与标签, 支持编辑, 删除, 分类排序和关联数据安全迁移.
- 支持日期, 状态, 分类, 优先级和多标签组合筛选, 并可保存为智能清单.
- 支持任务模板, 操作记录和创建, 修改, 批量操作与重复任务的完整撤销.
- 今天, 收集箱, 全部任务, 未来 7 天和已过期智能视图.
- 标题, 备注与子任务搜索, 组合筛选和常用键盘快捷键.
- 完整数据备份与恢复, 导入前执行严格结构校验并兼容 1.1 备份.
- IndexedDB 本地持久化, 数据不会上传到网络.
- 桌面和手机自适应界面.

## 目录结构

```text
apps/web/              Web 应用入口.
packages/domain/       领域模型与业务规则.
packages/application/  应用服务与用例编排.
packages/storage/      存储抽象与平台适配.
scripts/               仓库维护脚本.
```

## 开始开发

```bash
pnpm install
pnpm dev
```

打开终端显示的本地地址即可使用. 按 `N` 可快速新建任务, 按 `Command + K` 或 `Ctrl + K` 可聚焦搜索框.

## 质量检查

```bash
pnpm format:check
pnpm lint
pnpm typecheck
pnpm test
pnpm test:coverage
pnpm test:e2e
pnpm build
```
