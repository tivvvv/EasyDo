# EasyDo

EasyDo 是一个 local-first 的任务管理和日历应用. 当前提供 Web 端和 macOS 桌面端, 后续可继续演进到移动端.

当前开发版本为 EasyDo 1.11.0. 应用完全在设备本地运行, 不需要账号或互联网服务.

## 1.11 功能

- 新增每日规划中心, 集中处理过期和未安排任务, 并显示当天工作量与剩余容量.
- 自动规划会按重要性, 优先级和截止日期排序, 避开已有时间块并安排到工作时段内.
- 支持为单个任务寻找最早空档, 也可以把当天任务移回待规划区域.
- 新增全局命令面板, 按 `Command + P` 或 `Ctrl + P` 可以搜索并执行常用操作.
- 任务详情新增评论记录, 评论可随任务保存并通过全局任务搜索找到.
- 旧数据会在读取时自动补充新增字段, 无需手动迁移或重新创建任务.

## 1.10 功能

- SQLite 成为唯一权威数据源, 网页端和 macOS 客户端不再分别保存业务数据.
- macOS 客户端内置仅监听 `127.0.0.1` 的本机数据服务, 网页端与客户端通过同一服务无缝读写.
- 所有写入使用 SQLite 事务和递增版本校验, 多窗口同时操作时会在最新数据上重放本次修改, 防止静默覆盖.
- 数据变化通过本机实时事件同步到所有已打开界面, 并使用周期校对处理休眠和短暂断线.
- 1.9 及更早版本的 IndexedDB 会在首次运行时原样归档, 与现有 SQLite 快照合并后再安全清理.
- 系统托盘增加“在浏览器中打开”, 网页访问地址固定为 `http://127.0.0.1:24873`.
- 关闭 macOS 主窗口时应用继续在后台提供本机数据服务, 通过托盘可重新打开或完全退出.
- 网页端和客户端继续复用完全相同的 React 界面, 功能、视觉和交互保持一致.

- 统一使用应用内对话框处理输入, 确认和危险操作, 并提供全局错误恢复界面与异步失败反馈.
- 任务详情使用右侧抽屉, 支持前置依赖, 里程碑, 工作量估算, 实际专注时间和完整任务动态.
- 子任务支持拖动排序, 批量完成和折叠, 看板支持在制任务限制, 优先级泳道和跨分类移动.
- 时间线展示依赖阻塞和里程碑, 四象限紧急规则保存为本地偏好.
- 日历增加每日容量负载和空闲时间建议, 按住 Option 拖动定时任务可复制到新时间.
- 专注增加沉浸模式, 番茄轮次, 自动休息, 中断记录, 手动结束和本地生成的雨声与棕噪声.
- 习惯增加本地提醒, 暂停, 跳过日期, 目标变更历史和月度完成统计.
- macOS 使用 SQLite 保存当前数据和最近 20 份安全历史, 支持异常回退, 系统托盘, 全局快速添加, Dock 徽标和登录时启动.
- macOS 原生调度未来 90 天任务提醒和未来 30 天习惯提醒, 应用关闭后仍可由系统触发.
- 增加万级任务性能保护, 数据库第 6 版迁移, Web 与 Rust 原生测试, 可访问性扫描和自动化质量流水线.

- 年, 月, 连续 4 周, 周, 5 日, 3 日, 日和可配置范围的日程视图, 按时间展示每天任务.
- 日历计划收件箱集中展示未安排和已过期任务, 可直接拖到任意日历日期完成规划.
- 支持日历快速编辑, 跨天任务, 全天与定时任务转换, 拖动改期, 拖拽框选时间段和 15 分钟时间吸附.
- 支持重叠任务分栏, 冲突与过期提示, 当前时间线, 精确拖动预览和拖动调整时长.
- 支持舒适与紧凑密度, 周末显示, 7 天, 14 天和 30 天日程范围, 以及工作时段设置.
- 月视图提供当天安排, 完成进度和本周迷你日历, 周日历提供待安排任务区.
- 日历提供已安排数量, 计划时长, 时间冲突和待安排任务概览, 并支持分类图例与键盘选日.
- 新建, 编辑, 完成, 恢复, 复制, 手动排序, 多维分组排序, 批量修改和回收站管理.
- 任务分组支持组内直接创建, 自动预填日期, 分类或优先级, 子任务完成进度在清单和看板中保持可见.
- 区分任务, 事件和笔记, 支持重要标记, 分类分区, 本地附件, 起止日期, 起止时间, 时区, Markdown 备注预览和四级优先级.
- 每天, 工作日, 每周, 每月和每年重复任务, 支持按计划或完成日期计算, 月末, 月内周次与星期, 间隔, 结束日期, 完成次数, 排除日期和跳过本次.
- 重复系列支持仅本次, 本次及以后或全部范围修改, 完成历史与后续计划保持系列关联.
- 子任务支持独立日期, 时间, 优先级和备注, 并提供完整进度统计.
- 同一任务支持多个本地提醒, 可相对开始或结束时间触发, 并按任务时区正确处理夏令时.
- 支持中文自然语言快速添加, 可识别相对日期, 时间, 标签, 优先级, 时长和提醒.
- 自定义分类, 文件夹和标签, 支持编辑, 删除, 分类排序和关联数据安全迁移.
- 支持日期, 状态, 分类, 优先级和多标签组合筛选, 并可保存为智能清单.
- 支持任务模板, 操作记录和创建, 修改, 批量操作与重复任务的完整撤销.
- 今天, 收集箱, 全部任务, 未来 7 天和已过期智能视图.
- 效率工作台提供可就地创建的任务看板, 带日期刻度和范围导航的时间线, 可配置紧急范围的四象限, 番茄专注, 习惯打卡, 倒数日和完成趋势统计.
- 专注支持专注, 短休息和正计时三种模式, 计时状态跨页面和刷新持久保留.
- 习惯提供近 30 天热力记录, 当前与最长连续天数, 周进度, 周期和目标次数设置.
- 支持浅色, 深色和跟随系统主题, 以及专注和休息时长设置.
- 标题, 备注与子任务搜索, 组合筛选和常用键盘快捷键.
- 支持标准 ICS 日历导入和导出, 以及完整数据备份与恢复. 导入前执行严格结构校验并兼容 1.1, 1.2 和 1.3 备份.
- Web 端和 macOS 端使用同一份本机 SQLite 数据, 数据不会上传到互联网.
- 桌面和手机自适应界面.
- 提供基于 Tauri 2 的 macOS 桌面客户端, 复用完整 Web 端界面和数据能力.
- 桌面端支持原生系统通知, 窗口位置与尺寸恢复, macOS 原生菜单和透明标题栏.
- 支持构建 Apple Silicon 和 Universal macOS `.app` 与 `.dmg` 安装包, 最低兼容 macOS 12.

## 目录结构

```text
apps/web/              Web 应用入口.
apps/desktop/          Tauri 2 桌面客户端入口.
packages/domain/       领域模型与业务规则.
packages/application/  应用服务与用例编排.
packages/storage/      存储抽象与平台适配.
scripts/               仓库维护脚本.
```

## 开始开发

```bash
pnpm install
pnpm dev
```

该命令会同时启动本机数据服务和 Web 开发服务器. 打开终端显示的本地地址即可使用. 正式网页入口由 macOS 客户端提供, 地址为 `http://127.0.0.1:24873`. 按 `N` 可快速新建任务, 按 `Command + K` 或 `Ctrl + K` 可聚焦搜索框, 按 `Command + P` 或 `Ctrl + P` 可打开全局命令面板.

macOS 桌面端开发:

```bash
pnpm desktop:dev
```
