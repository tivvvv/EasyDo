# EasyDo

EasyDo 是一款以日历为核心的本地任务管理应用. 它把任务, 日程, 每日规划和效率工具整合在同一个工作区, 帮助用户明确每天需要完成的事情.

当前版本为 `1.11.0`, 提供 macOS 客户端和网页界面. 两个界面使用同一份本机 SQLite 数据, 不需要账号, 不会将任务上传到网络.

## 主要功能

### 日历与每日规划

- 年, 月, 4 周, 周, 5 日, 3 日, 日和日程视图.
- 全天任务, 定时任务, 跨天安排, 时区和重复规则.
- 拖动改期, 调整时长, 框选时间段和 15 分钟吸附.
- 时间冲突, 当日负载, 空闲时段和未安排任务提示.
- 自动规划过期及未安排任务, 并避开已有时间块.
- 锁定固定安排, 防止自动规划移动任务.

### 任务管理

- 任务, 事件和笔记三种条目类型.
- 分类, 文件夹, 分区, 标签, 优先级和重要标记.
- 子任务, 前置依赖, 里程碑, 预计时长和附件.
- 每天, 工作日, 每周, 每月和每年重复.
- 重复系列支持修改本次, 本次及以后或全部任务.
- 搜索, 组合筛选, 智能清单, 模板和批量操作.
- 回收站, 操作记录和撤销.

### 提醒

- 单个任务可以设置多个提醒.
- 提醒可以相对开始时间或结束时间触发.
- 支持子任务提醒和连续提醒.
- macOS 客户端使用系统通知调度任务和习惯提醒.
- 应用恢复运行时会补发最近 24 小时内遗漏的最新提醒.
- 网页端与客户端共享提醒记录, 避免重复通知.

### 效率工具

- 任务看板, 优先级泳道和在制任务限制.
- 项目时间线和艾森豪威尔四象限.
- 番茄专注, 正计时, 自动休息和中断记录.
- 雨声和棕噪声等本地白噪声.
- 习惯打卡, 周期目标, 暂停, 跳过和趋势统计.
- 倒数日和任务完成统计.

### macOS 客户端

- 与网页端一致的功能和界面.
- 菜单栏常驻, 关闭主窗口后仍可提供提醒和共享数据服务.
- 独立快速收集窗口, 无需先打开主界面.
- Dock 待办数量, 登录时启动和窗口状态恢复.
- 支持 Apple Silicon 和 Intel Mac 的 Universal 安装包.

## 使用教程

### 1. 启动应用

安装并打开 EasyDo macOS 客户端. 主窗口关闭后应用仍会保留在菜单栏, 可以从菜单栏重新打开或完全退出.

客户端运行时, 浏览器访问 [http://127.0.0.1:24873](http://127.0.0.1:24873) 即可使用同一工作区. 该地址只允许本机访问.

### 2. 添加任务

点击 `添加任务` 或按 `N` 打开完整编辑器. 页面顶部的快速收集栏适合直接输入自然语言, 例如:

```text
明天下午3点 写周报 @工作 #重点 !高 提前30分钟 每周
```

可识别的常用语法:

| 输入                     | 作用         |
| ------------------------ | ------------ |
| `今天`, `明天`, `下周一` | 设置日期     |
| `下午3点`, `今晚`        | 设置时间     |
| `@工作`                  | 选择分类     |
| `#重点`                  | 添加标签     |
| `!高`, `!中`, `!低`      | 设置优先级   |
| `持续2小时`              | 设置预计时长 |
| `提前30分钟`             | 设置提醒     |
| `每天`, `工作日`, `每周` | 设置重复规则 |

macOS 中按 `Command + Shift + N` 可以在任意界面打开快速收集窗口.

### 3. 安排日历

在日历顶部切换需要的时间范围. 可以拖动任务调整日期和时间, 拖动任务底部调整时长, 或在日视图中框选空白时间创建任务.

`规划今天` 会按照重要性, 优先级和截止日期自动寻找可用时间. 固定会议或不可移动的安排应开启 `锁定时间块`.

### 4. 整理任务

使用分类表示长期领域, 使用文件夹组织多个分类, 使用分区表示项目阶段, 使用标签补充跨分类属性. 常用筛选条件可以保存为智能清单.

任务详情中的评论会立即保存. 附件和其他字段在点击 `保存更改` 后写入.

### 5. 设置提醒

在任务详情中先设置日期和时间, 再添加一个或多个提醒. 连续提醒最多触发 3 次, 适合重要且容易遗漏的事项.

首次使用需要在 `设置与数据` 中开启通知权限. 如果客户端在提醒时间处于关闭状态, macOS 已调度的系统通知仍可以触发.

### 6. 使用效率工作台

`效率工作台` 包含看板, 时间线, 四象限, 专注, 习惯和统计. 专注计时在切换页面或刷新后仍会保留当前状态.

## 快捷键

| 快捷键                | 功能                    |
| --------------------- | ----------------------- |
| `N`                   | 新建任务                |
| `Command + K`         | 聚焦搜索                |
| `Command + P`         | 打开命令面板            |
| `Command + Shift + N` | 打开 macOS 快速收集窗口 |
| `Escape`              | 关闭当前浮层            |

Windows 和 Linux 浏览器可以使用对应的 `Ctrl` 组合键.

## 数据与备份

macOS 数据库默认位于:

```text
~/Library/Application Support/com.tivvvv.easydo/easydo.db
```

请不要直接编辑数据库文件. EasyDo 使用事务, 版本校验和最近 20 份安全历史降低异常写入风险. 网页端与客户端会实时同步本机数据库中的变化.

在 `设置与数据` 中可以导出完整备份, 恢复备份, 或导入和导出标准 ICS 日历文件. 升级应用时会自动补充新增字段, 不会重新创建数据库.

EasyDo 当前不提供账号, 云同步或多人协作. 跨设备使用需要后续的加密同步能力, 不能通过复制正在使用的数据库文件实现.

## 本地开发

环境要求:

- Node.js 22 或更高版本.
- pnpm 11 或更高版本.
- Rust stable, 仅桌面端开发需要.
- macOS 12 或更高版本, 仅 macOS 客户端构建需要.

安装依赖并启动本地数据服务与网页端:

```bash
pnpm install
pnpm dev
```

启动 Tauri 客户端:

```bash
pnpm desktop:dev
```

## 项目结构

```text
apps/web/              React 网页界面和交互测试.
apps/desktop/          Tauri 2 macOS 客户端和本机数据服务.
packages/domain/       领域模型与业务规则.
packages/application/  应用服务和用例编排.
packages/storage/      本地存储实现与历史迁移.
scripts/               开发, 校验和发布脚本.
```

核心技术包括 React, TypeScript, Vite, pnpm workspace, Tauri 2 和 SQLite. 网页端与客户端复用相同的界面和领域逻辑.

## 质量检查

提交前执行:

```bash
pnpm format:check
pnpm lint
pnpm typecheck
pnpm test:coverage
pnpm build
cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml
pnpm test:e2e
pnpm release:check
```

测试范围包括领域规则, 数据迁移, SQLite 并发写入, React 组件, 桌面及移动视口, 可访问性和视觉回归.

## 构建 macOS 安装包

```bash
pnpm release:macos
```

该命令校验所有子项目版本, 清理旧产物并生成唯一的 Universal DMG. 正式分发前仍需配置 Apple Developer 签名和公证凭据.
